# CREAIT runs on EOS (Ninety.com flavor)

When the user asks about operating cadence, Rocks, scorecards, meetings, the Accountability Chart, or "how should I run my company" — these are the rules we follow.

## The 8 EOS components

1. **Vision/Traction Organizer (V/TO)** — 8 boxes that live on /vision: Core Values, Core Focus (purpose + niche), 10-Year Target, Marketing Strategy (target market + Three Uniques + Proven Process + Guarantee), 3-Year Picture, 1-Year Plan, Quarterly Rocks, Issues List.
2. **Accountability Chart** — Functions (seats), not people. Each seat has 3-5 responsibilities. Then put the right person in each seat. CREAIT seats: Visionary (Maurice), Integrator (Maurice — needs to graduate to John long-term), Sales & Marketing (Maurice), Operations (John + Jaylyn), Finance & Admin (Ashaela).
3. **Rocks** — 3-7 quarterly priorities. MUST be SMART. One owner each. Status: on_track / off_track / complete / incomplete / dropped. Plus weekly Green/Yellow/Red snapshot in L10.
4. **Scorecard / Data** — 5-15 weekly KPIs. Each has owner + target + unit + source. Lives on /level-10 → Scoreboard.
5. **Issues List** — Short-term (resolve this L10) vs Long-term (parks for Quarterly/Annual planning). Lives on /level-10 → IDS.
6. **Process** — Documented, followed by all. (We house this in the second brain `/data/company/*.md` files.)
7. **Meeting Pulse** — Weekly L10 (90 min), Quarterly Planning (1 day), Annual Planning (2 days).
8. **Traction** — Discipline + accountability. Rocks + scorecard + L10 every week.

## Weekly L10 Meeting — exact 90-minute structure

| Section | Time | Rules |
|---|---|---|
| **Segue** | 5 min | Each person shares 1 personal + 1 business good news. Stay connected as humans. |
| **Scorecard** | 5 min | Owner says "on track" or "off track" per KPI. **NO discussion** — off-track items go to Issues. |
| **Rock Review** | 5 min | Each Rock owner says on-track / off-track. **NO discussion** — drop to Issues if needed. |
| **Customer/Employee Headlines** | 5 min | One-sentence updates. Off-topic ⇒ Issues. |
| **To-Do Review** | 5 min | Done / not done per item. Roll over or drop to Issues. |
| **IDS (Identify, Discuss, Solve)** | 60 min | Top 3 issues. Identify root cause → discuss until clear → solve permanently. |
| **Conclude** | 5 min | Recap new To-Dos with owners. Everyone rates the meeting 1-10. Target ≥ 8. |

**Critical L10 rules:**
- Same day, same time, same agenda. Start AND end on time.
- 3-7 participants max.
- Save discussions for IDS. Before IDS, the only words allowed are: yes, no, on track, off track, make it an issue, make it a to-do.
- During the week if anyone brings the leader an issue, ask "can it wait for L10?" — saves ~1 month/year of time.

## Rocks — discipline rules

- **3-7 Company Rocks max per quarter.** More = won't hit them.
- **Single owner per Rock.** One throat to choke. Owner can delegate Milestones but owns the outcome.
- **SMART criteria mandatory.** Specific, Measurable, Achievable, Relevant, Time-bound. "Improve customer service" is not a Rock. "Hit 95% CSAT via monthly survey of 100+ customers by March 31" is.
- **Milestones every ~30 days.** Each Rock has 3-5 sub-checkpoints so you catch slippage early.
- **Weekly status:** Green (on track) / Yellow (at risk) / Red (off track). Yellow/Red ⇒ Issue this week.
- **Quarterly target:** 80%+ completion rate. Below 80% means we over-commit; calibrate next quarter.

## Quarterly Planning Meeting (1 day, 8 hours)

1. **Personal/business check-in** (20 min)
2. **Previous quarter Rock review** (30 min) — Complete/Incomplete binary. If <80%, "what patterns?"
3. **Learning extraction** (30 min)
4. **V/TO health check** (45 min)
5. **Issues list build** (30 min) — brainstorm 20-50 issues, no solutions
6. **Set next quarter Company Rocks** (2 hours): brainstorm → Keep/Kill/Combine → narrow to 3-7 → SMART refinement
7. **Individual Rocks** (45 min) — each person picks 3-7 personal Rocks supporting Company Rocks

## Annual Planning Meeting (2 days)

Day 1: Previous year review + V/TO refresh + 3-year picture update.
Day 2: 1-year plan + next quarter Rocks.

## GWC — Right person, right seat

For each person in each seat, rate:
- **Get it (+/+−/−):** Truly understand how this role contributes to success?
- **Want it (+/+−/−):** Genuinely excited to do this work daily?
- **Capacity (+/+−/−):** Have the skills and bandwidth?

3 plusses = right person in right seat. Any minus = needs a conversation.
