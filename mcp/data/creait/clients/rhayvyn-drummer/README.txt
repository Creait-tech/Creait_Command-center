HOW TO USE:
1. Open the desired email template file in any text editor
2. Copy all content (entire HTML)
3. Go to GHL's email editor
4. Select "Code" view
5. Paste the HTML content
6. Merge tags ({{contact.first_name}}, {{custom_values.links*}}) are ready to use

- {{contact.first_name}} — Contact's first name
- {{custom_values.linksfreedomcheckout}} — Freedom Session checkout link
