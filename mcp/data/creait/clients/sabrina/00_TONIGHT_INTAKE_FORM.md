## SECTION 8 — Red Flags to Watch For During the Call

Things that would change the build materially if they come up:

- 🚩 She has more than 50 active clients → migration is bigger, push Day 1 of build to be data-only
- 🚩 She's licensed in multiple states → every footer + form needs state-specific disclosures
- 🚩 Easy Links has no API AND no Zapier → fall back to CSV-only sync, warn her of the lag
- 🚩 She has an active lawsuit / complaint → tighten AI agent guardrails around claims
- 🚩 She's hired (or about to hire) someone → build with multi-user + round-robin from Day 1
- 🚩 She uses an accounting tool that doesn't integrate → defer accounting connection to Phase 2
- 🚩 She's planning to change her domain → delay SEO-sensitive work
- 🚩 She has existing email sequences running in Easy Links → plan orderly migration; don't double-send
