## 🚫 Hit walls — could NOT complete

### Form fields drag-drop (form-builder iframe)

The form-builder iframe (`leadgen-apps-form-survey-builder.leadconnectorhq.com`) has its accessibility tree exposed but uses HTML5 drag-drop to add palette fields (Single Dropdown, Multi Line, Date Picker, etc.). Click and double-click both fail to add fields (palette items only register drag start). The "Add Object Fields" panel exposes existing custom fields but requires the same drag-drop gesture or a checkbox interaction not visible to a11y.

**Workaround attempted:** Capture the form-builder API at `backend.leadconnectorhq.com/forms/{id}` and PUT the form structure directly. The iframe origin has a different cookie/JWT scope than the parent (`app.getcreait.com`) and direct fetches from parent context return 401. Cross-origin write blocked.

**Realistic path forward:**
- A human at the keyboard drags the 5 needed fields (Organization, Single Dropdown for LoB, State, Date Picker, Multi Line for Notes) — 2 minutes of work.
- OR: a Playwright script with proper drag-drop coordinates can drive it (Playwright's `mouse.dragAndDrop` simulates real DragEvents). Out of scope today.

The form is functional with the existing 5 fields (First Name, Last Name, Business Name, Phone, Email) for an MVP submission test. LoB / State / Date / Notes can be added via human click later.
