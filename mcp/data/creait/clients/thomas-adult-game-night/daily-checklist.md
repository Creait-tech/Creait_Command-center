# Daily Checklist — 5 Minutes Every Morning

Print this. Tape it next to your laptop. Run through it with coffee.

---

## 🚨 RED LINE ITEMS

If you see any of these, drop everything and respond:

- 1-star review posted (1 hour SLA)
- Customer texting "speak to Thomas" / "owner" / "manager"
- Critical-priority SMS from the system (🚨🚨)
- Refund request (your call, never auto-delegate)
- Press / journalist inquiry (your call)
- Stripe payment dispute (your call)
