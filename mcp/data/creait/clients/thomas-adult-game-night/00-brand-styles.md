# Adult Game Nights — Landing Page Brand Styles

Apply these styles to every landing page in this directory.

## Color Palette
| Token | Value | Use |
|-------|-------|-----|
| Primary Red | `#D50000` | CTAs, accents, emphasis |
| Secondary Yellow | `#FFD600` | Highlights, hover states, badges |
| Dark | `#1A1A1A` | Headings, primary text |
| Background | `#FFFFFF` | Page background |
| Muted | `#666666` | Secondary text |
| Surface | `#F5F5F5` | Cards, dividers |

## Typography
- **Headings:** Bold, sans-serif (Inter / Manrope / system-ui)
- **Body:** Regular, 16px desktop / 15px mobile
- **CTA buttons:** UPPERCASE, 600 weight, 14px tracking +0.5

## Spacing
- Section vertical padding: 96px desktop / 64px mobile
- Container max-width: 1200px (centered)
- Grid gap: 32px

## Responsive Breakpoints
- Mobile: 375px
- Tablet: 768px
- Desktop: 1280px

Test all pages at the three widths.

## CTAs
- Primary CTA: Red `#D50000` background, white text, 16px padding, 4px border-radius
- Secondary CTA: White background, red border + text
- Hover: Yellow `#FFD600` background, dark `#1A1A1A` text

## Imagery
- Hero images: 16:9 minimum, brand colors visible
- Product photos: square, white background, consistent shadow
- Lifestyle/event photos: full-bleed, color-corrected

## Common components
- Sticky nav (logo + 3 links + phone)
- Hero (full-bleed image, headline left, CTA top-right)
- Feature grid (4-up with icon + label + body)
- Testimonial cards (3-up, quote + name + photo)
- FAQ accordion (4-6 questions)
