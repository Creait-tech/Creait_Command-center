## What we're NOT doing in the first 90 days

- Building a custom mobile app (CreateOS LeadConnector mobile is enough)
- Running paid ads before organic traffic + workflow KPIs are healthy
- Adding the 4th, 5th, 6th game beyond what's already in pipeline

- Building integrations beyond what's in the spec (no scope creep)

Stay disciplined. Win the 90 days first. Scale comes after.
