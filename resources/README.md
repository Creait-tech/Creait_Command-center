# CREAiT Assessment Resources

This folder contains the reference methodology and delivery materials for the **CREAiT Business Value & Leverage Diagnostic**.

It is intentionally located at the repository root, outside the `web/`, `mcp/`, and `infra/` application directories. The Command Center build, runtime, Docker configuration, and deployment pipeline do not import, compile, publish, or execute these files.

| File | Purpose |
|---|---|
| `CREAIT-Business-Value-and-Leverage-Diagnostic-Methodology.md` | Product design and diagnostic-methodology reference. |
| `CREAIT-Master-Intake-Questionnaire.md` | Full client intake source of truth. |
| `CREAIT-Scoring-Engine-and-Rubrics.md` | 30-indicator scoring method, evidence rules, and opportunity logic. |
| `CREAIT-Facilitator-Guide.md` | Live diagnostic-intensive and results-session facilitation guide. |
| `CREAIT-Sample-Executive-Blueprint.md` | Composite example of the client-facing Executive Blueprint. |

These files are reference documentation only. Any production application changes must be implemented deliberately in the relevant source directory and should not depend on this folder at runtime.
